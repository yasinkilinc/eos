# Operational memory — this workspace's H rows

The plan is `tools/eos/docs/plans/operational-memory.md` (upstream
`docs/plans/operational-memory.md`, target EOS 1.0.0). Its §3 status table
holds every row, M (engine) and H (host), and is the only place status
lives. This file maps each H row to what it means **here** — the engine plan
deliberately names no host. Order: every M row first, then H, except H-00
and H-05 which depend on nothing and may be done at any time.

Measured 2026-09-24, before any of this: an atlas session loads
**113,493 tokens** unconditionally (`CLAUDE.md` 6,021 + `atlas.md` 2,477 +
`project-intelligence` 5,142 + `dev-atlas` 17,760 + `dev-nexus` **81,689**).
The deploy-to-env1 procedure is ~40 lines inside `dev-nexus`. The brief EOS
would add is ~200 tokens, and it is not wired in `nexus/`: the brief hooks
exist in 13 service directories and had run 3 times in all of history, all in
one session, because sessions start from `nexus/`.
